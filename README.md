# 🎵 FishPot

> Терминальный музыкальный плеер для YouTube с 3D-визуализацией в реальном времени, караоке, локальной библиотекой и скачиванием в MP3.

![Rust](https://img.shields.io/badge/Rust-1.75%2B-orange?logo=rust)
![License](https://img.shields.io/badge/license-MIT-blue)
![Platform](https://img.shields.io/badge/platform-Linux-lightgrey)
![Ratatui](https://img.shields.io/badge/TUI-Ratatui-purple)

**FishPot** — это полноценный музыкальный центр прямо в терминале. Он ищет треки на YouTube, воспроизводит их без открытия браузера, скачивает в MP3 и рисует 8 разных визуализаторов, реагирующих на частоты в реальном времени. Построен на Rust с использованием `ratatui`, `mpv`, `yt-dlp` и `cava`.

## ✨ Возможности

### 🎧 Воспроизведение
- **Стриминг с YouTube** через `mpv` + `yt-dlp` — без браузера и без рекламы.
- **Локальная библиотека** — играет MP3/FLAC/M4A/WEBM/WAV прямо из папок.
- **Караоке** — синхронизированный текст подгружается с [lrclib.net](https://lrclib.net) с подсветкой текущей строки.
- **Перемотка** на ±5 секунд или на точное время (`s` → `1:30`).
- **Регулировка громкости** и пауза с клавиатуры.
- **Режимы повтора**: выкл / все / один.
- **Shuffle** — случайный порядок треков.

### ⬇️ Скачивание
- **Скачивание в MP3** с высоким качеством (VBR ~245 kbps) через `yt-dlp` + `ffmpeg`.
- **Прогресс-бар в реальном времени** — проценты обновляются каждую секунду.
- **Скачивание плейлистов** — по ссылке создаётся папка с названием плейлиста и пронумерованными треками.

### 📁 Управление файлами
- **Файловый менеджер** прямо в интерфейсе: навигация по папкам, создание новых.
- **Фильтр файлов** — начните вводить название, и список мгновенно отфильтруется.
- **Переименование** и **удаление** файлов и папок (с подтверждением) без выхода из плеера.

### 🎨 Визуализация (8 режимов)
Все визуализаторы реагируют на реальный аудиопоток через `cava` и рисуются шрифтом Брайля (максимальная детализация в терминале):

| # | Режим | Описание |
|---|-------|----------|
| 0 | **3D Сфера** | 3D-каркасная сфера, деформируется от басов |
| 1 | **Радиальные волны** | 32 луча спектра из центра с RGB-градиентом |
| 2 | **Туннель** | Полёт сквозь неоновый туннель, ускоряется от басов |
| 3 | **Матрица** | Классический "цифровой дождь" в RGB |
| 4 | **RGB Череп** | ASCII-череп с пульсирующими глазами и мерцающими костями |
| 5 | **ДНК** | Двойная спираль, вращается и дышит от басов |
| 6 | **Аквариум** | Рыбки, водоросли, пузырьки и цветной фон воды |
| 7 | **Ночной поезд** | Паровоз с дымом, звёздным небом и мерцающими облаками |

Плюс **отдельный эквалайзер** (клавиша `E`).

### 🎨 Кастомизация
- **Полноэкранный визуализатор** (`F`) — видна только графика и статус.
- **Скрытие панели YouTube** (`Y`) — визуализатор занимает всё место.
- **цветовые темы** можно настраивать через `~/.config/yt-music-tui/config.toml`. Готовые пресеты:
- **Сохранение истории** поисковых запросов (последние 20).

| Клавиша | Действие |
|---|---|
| `/` | Поиск музыки на YouTube |
| `i` | Импорт плейлиста/трека по URL |
| `Y` | Скрыть/показать панель YouTube |
| `F` | Полноэкранный визуализатор |
| `V` | Сменить визуализатор (8 режимов) |
| `E` | Открыть эквалайзер |
| `A` | Включить/выключить ambient-эффект |
| `L` | Открыть караоке (текст песни) |
| `?` | Показать справку |
| `q` | Выход из приложения |

### Воспроизведение
| Клавиша | Действие |
|---|---|
| `Enter` | Играть выбранный трек |
| `Space` / `p` | Пауза / Продолжить |
| `h` / `l` | Перемотка на −5 / +5 секунд |
| `s` | Перемотка на точное время (формат `mm:ss`) |
| `+` / `-` | Громкость ±5% |
| `n` | Следующий трек |
| `R` | Режим повтора: Выкл → Все → Один |
| `r` | Случайный порядок (Shuffle) |

### Локальная библиотека
| Клавиша | Действие |
|---|---|
| `Enter` | Войти в папку / Играть файл |
| `Backspace` | Вернуться на уровень выше |
| `f` | Фильтр файлов по названию |
| `r` | Переименовать файл |
| `d` | Удалить файл или папку (с подтверждением) |
| `m` | Создать новую папку |
| `F5` | Обновить список файлов |

### Скачивание
| Клавиша | Действие |
|---|---|
| `D` | Скачать выбранный трек из YouTube или тот, что играет сейчас |
| `i` | Скачать плейлист по URL |

|---|---|
| `Tab` | Переключить фокус между панелями (Результаты ↔ Локальная) |
| `↑` / `k` | Вверх по списку |
| `↓` / `j` | Вниз по списку |
| `Enter` | Играть / Войти |

## ⚙️ Конфигурация

Файл конфига создаётся **автоматически при первом запуске** по пути:

``````
~/.config/fishpot/config.toml
``````

Если файла нет — Fishpot создаст его с настройками по умолчанию Все изменения вступают в силу **после перезапуска приложения**.
### Полный пример конфига

``````toml
# Куда скачивать треки (абсолютный путь)
download_dir = "/home/user/Music/fishpot"

# Стартовый визуализатор (0–7)
# 0 = 3D Сфера, 1 = Радиальные волны, 2 = Туннель, 3 = Матрица,
# 4 = RGB Череп, 5 = ДНК, 6 = Аквариум, 7 = Ночной поезд
viz_mode = 0

# Ambient-эффект (частицы-искры по экрану)
ambient_effect = false

[theme]
bg_color = "#1a1b26"
active_border = "#7aa2f7"
inactive_border = "#3b4252"
text_color = "#c0caf5"
accent_color = "#bb9af7"
selected_bg = "#283250"

# Прозрачность панелей (виден фон терминала)
transparent_panels = false
transparent_visualizer = false

# Максимум частиц ambient-эффекта (минимум 50, рекомендуется 100–500)
ambient_count = 200
``````

### Описание параметров

#### Корневые настройки

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `download_dir` | String | `~/Music/fishpot` | Папка для скачанных треков. Создаётся автоматически, если её нет. |
| `viz_mode` | Integer (0–7) | `0` | Визуализатор при старте. Переключение клавишей `V` **не сохраняется** — чтобы закрепить режим, отредактируйте значение вручную. |
| `ambient_effect` | Boolean | `false` | Включён ли ambient-эффект по умолчанию. В приложении переключается клавишей `A`. |

#### Настройки темы (секция `[theme]`)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `bg_color` | `#1a1b26` | Основной фон приложения (панели, строка поиска, прогресс-бар). |
| `active_border` | `#7aa2f7` | Цвет рамки панели, **на которой сейчас фокус** (куда направлены стрелки). |
| `inactive_border` | `#3b4252` | Цвет рамки панелей без фокуса. |
| `text_color` | `#c0caf5` | Обычный текст в списках (названия треков, файлов). |
| `accent_color` | `#bb9af7` | Акцент: заголовки всплывающих окон, заливка прогресс-бара, спиннер загрузки. |
| `selected_bg` | `#283250` | Фон **выделенного** элемента в списке. |
| `transparent_panels` | `false` | Если `true` — панели используют фон терминала вместо `bg_color`. Работает только если в самом терминале (Alacritty, Kitty) настроена прозрачность (`opacity = 0.85`). |
| `transparent_visualizer` | `false` | Убирает тёмный фон у визуализатора. |
| `ambient_count` | `200` | Максимум частиц ambient-эффекта одновременно. Минимум 50, разумный максимум ~500. |

### Полностью прозрачный интерфейс

Если хотите, чтобы панели «парили» над вашими обоями:

1. Включите прозрачность в Alacritty:
   ``````toml
   [window]
   opacity = 0.85
   ``````

2. В конфиге Fishpot:
   ``````toml
   [theme]
   transparent_panels = true
   transparent_visualizer = true
   ``````

### Сброс к дефолту

Удалите файл и запустите Fishpot заново:

``````bash
rm ~/.config/fishpot/config.toml
fishpot
``````

Будет создан новый конфиг с настройками по умолчанию. **Скачанные треки, история поиска — не затрагиваются** (они лежат в отдельных файлах).

### Проверка синтаксиса TOML

Если после редактирования Fishpot молча создал новый дефолтный конфиг — значит, в TOML была ошибка. Проверить можно через Python:

``````bash
python -c "import tomllib; tomllib.load(open('$HOME/.config/fishpot/config.toml','rb'))"
``````

Если ошибок нет — команда ничего не выведет. Если есть — покажет строку и столбец с проблемой.

## 📋 Требования

| Зависимость | Назначение | Arch Linux |
|---|---|---|
| **`mpv`** | Воспроизведение аудио и IPC-управление | `sudo pacman -S mpv` |
| **`yt-dlp`** | Поиск и скачивание с YouTube | `sudo pacman -S yt-dlp` |
| **`ffmpeg`** | Конвертация в MP3 | `sudo pacman -S ffmpeg` |
| **`cava`** | Захват спектра частот (опционально) | `sudo pacman -S cava` |
| **Rust 1.75+** | Сборка | `sudo pacman -S rust` |

Если `cava` не установлена, визуализаторы будут работать на симуляции (менее красиво, но функционально).

### 📦 Установка

**Arch Linux (бинарник):**
```bash
tar -xzf fishpot-v0.2.0-x86_64.tar.gz
chmod +x fishpot
sudo mv fishpot /usr/local/bin/
fishpot
```

**Из Исходников:**    
```bash
git clone https://github.com/AkyLich1328/fishpot.git
cd fishpot
cargo build --release
```
